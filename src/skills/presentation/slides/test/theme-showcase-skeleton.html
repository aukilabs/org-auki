Slide types

What's in the system

Every type has a specific job — use the most precise one for the content you have.

  • Title, Section, Statement — structure slides; set the frame for what follows
  • Content — bullets or prose; the workhorse of any deck
  • Stats, Compare — when a number is the point and size matters
  • Graphic, Half — charts, diagrams, SVG with CSS token theming
  • Split, Highlights, Steps, Table, Image — the rest of the palette
Context

Why this system exists

Every presentation generated by the Pulse system is a single self-contained HTML file. No build step, no server, no external dependencies at runtime — open it in any browser, present it, share it, archive it forever.

The design system defines the visual language once. The skill is the author — it reads the content, chooses the narrative arc, picks the slide types, and writes the markup. No template-filling, no form completion.

Comparison & Layout

Approach

Template-filling vs. authoring

Template-filling
  • Fixed sections in a fixed order — context doesn't change the structure
  • Every slide has a placeholder waiting to be filled
  • Visual output varies only in content, never in shape
  • Produces competent decks that feel the same regardless of what happened
Authoring
  • Shape follows story — quiet weeks are short; big weeks earn their length
  • Slide types are chosen for what they communicate, not filled because they exist
  • The arc is committed before any slide is written
  • A reader unfamiliar with the work understands what happened and why it matters

Components

What the system includes

Theme system

CSS custom property tokens for colour, type, and spacing — one source of truth, overridden per brand

Self-contained output

Single HTML file with all fonts, logos, CSS, and JS inlined — no network requests at viewing time

Dark / light toggle

Instant theme switching via localStorage — persists across sessions, no flash on load

PDF export

Print-PDF mode via Reveal.js — pixel-perfect export at 1280×720, no layout artifacts

Image gallery

Attach screenshots to any slide — per-slide image button and gallery overlay injected automatically

Magnify & lightbox

Hover-to-magnify loupe and click-to-expand lightbox — zero per-slide wiring required

Architecture

How themes layer

  • reveal.css — base layout engine, inlined first
  • auki-theme.css — all slide layouts, CSS tokens, dark/light mode
  • brand-theme.css — token overrides only; cascade wins via source order
  • No layout rules duplicated — one source of truth for structure
