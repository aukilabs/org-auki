01 TL;DR

Good week. The task card redesign went to production and early signals from the pilot stores are better than expected — missed assignment rate is down measurably in the first two days. The AR overlay rendering refactor is done and frame rates on lower-end devices are now acceptable. Still working on the offline sync edge cases; that's the main thing left before we can expand the pilot.

Pilot stores, first 48h
  • Task card redesign — shipped to all pilot locations. New layout surfaces priority and deadline more clearly. The 12% drop in missed assignments in the first 48 hours is encouraging, though it's too early to call it confirmed.
  • AR overlay rendering refactor — rewrote the render pipeline to batch draw calls. Frame rate on our lowest-spec test device (2019 Samsung A50) went from 21fps to 38fps. Overlay is now usable on devices we previously considered borderline.
  • Push notification reliability — fixed a race condition that caused task notifications to arrive after the task window had already closed. Affected around 8% of notifications in high-concurrency stores.

The task card redesign took three iterations and two rounds of pilot feedback to get right. The version that shipped is meaningfully simpler than what we started with — the first prototype had seven data points per card; the final has three. That reduction is almost certainly what's driving the missed assignment improvement.

03 What's in progress

Offline sync edge cases

The main remaining work before pilot expansion. The sync logic handles the happy path well but has three known failure modes when a device comes back online after an extended offline period: duplicate task completion events, stale assignment state, and a rare deadlock in the queue processor. All three are reproduced reliably in tests. Fixes for the first two are done; the deadlock is more complex and is the current focus.

Store manager dashboard

Early implementation of the compliance overview screen that store managers see. The task assignment pipeline is solid enough that we can now surface meaningful aggregate data without it being noisy. Targeting a first internal review next week — not shipping until the offline sync work is done, but building in parallel so they land together.
