03 What's in progress

Zero-knowledge privacy layer

The goal is to let devices prove membership in a Domain without revealing their identity to the relay node — the relay knows a valid device is there, not which device. The ZK proof system is chosen (Groth16 via snarkjs), circuits are written and tested in isolation, and the integration into the join flow is partially done. The blocker is verification time: on-device proof verification is currently taking ~800ms on a mid-range Android (Galaxy A54), which is too slow to sit in the join flow without degrading the user experience noticeably.

Two paths being explored: batching verifications to amortize the cost, and moving verification server-side. The batching approach preserves the privacy properties; server-side verification technically does not (the server would see the proof). If batching can get us to under 200ms we use it. If not, we need a design conversation about what server-side verification means for the privacy guarantees we're claiming.

Validator incentive design

Working on how validators are rewarded for relay work. The core design question is measurement: a validator that handles many low-quality, high-churn connections should not earn more than one maintaining fewer, stable, high-throughput connections. Three candidate models are on the table, differing in how they weight connection stability versus raw throughput. Running economic simulations this week. The connection pooling throughput gain has changed the input assumptions — need to re-run last week's simulations with updated baseline numbers before presenting a recommendation.

Cross-domain transform protocol

Collaboration with Robin on the spatial layer. The protocol defines how pose data transforms between Domains that share a physical boundary — when a device moves from one Domain into an adjacent one, the coordinate frames need to be reconciled without a cloud round-trip. The protocol is fully specified on paper. Implementation is blocked on a coordinate frame convention decision that has been open for three weeks. A dedicated session with Robin is scheduled for Thursday to force a resolution.
