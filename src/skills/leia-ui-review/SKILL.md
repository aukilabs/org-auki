# LEIA — Logic, Intuition, Ergonomic, Aesthetic

Any UI change affects at least one of four dimensions. Score the delta on each, then check whether the change is optimizing for what you actually need.

## Dimensions

- **Logic** — internal consistency. Example: is OK always to the right of Cancel?
- **Intuition** — external consistency. Does it work like things users are already used to? Example: can I click my profile picture to edit it?
- **Ergonomic** — how much exertion does this require? Did you add or remove friction? Example: fewer clicks, less cognitive load.
- **Aesthetic** — how visually appealing is it?

## How to use

1. For each dimension, score the delta: +, 0, or −.
2. Note which dimension(s) the change is primarily optimizing for.
3. Check: is that the right target for this context? Not all four matter equally everywhere.

A change that is net positive across all four is rare. A change that is +Ergonomic and −Aesthetic may still be the right call if you're optimizing for speed of use.
