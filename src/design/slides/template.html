What shipped

  • Relay protocol v2 — new binary frame format, 40% lower message overhead. Now default in all regions.
  • Domain join fast-path — skips handshake negotiation for previously-seen devices. Covers 78% of joins.
  • Pose pipeline batching — batches sensor reads into 16ms windows. Reduces CPU wake-ups by 60%.
  • Nightly test suite stability improved — flakiness rate down from 14% to 3%.

Before and after

Before — Protocol v1
  • Full handshake on every domain join regardless of device history
  • 420ms average latency on fresh join
  • Stateless: no knowledge of previously-seen devices
  • 14% CPU overhead from redundant negotiation cycles
After — Protocol v2
  • Fast-path for known devices — skips full handshake. Covers 78% of joins.
  • 180ms average latency — 2.3× improvement on target path
  • Device session cache persists across relay restarts
  • CPU overhead reduced by 60%
