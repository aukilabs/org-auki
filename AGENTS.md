This is the `org-auki` repo — shared organizational context for Auki Labs.

The canonical entry point for AI agents is at [`src/AGENTS.md`](src/AGENTS.md). That `src/` directory is what every Auki exocortex symlinks in as `org-auki/`, so when an agent is running inside a personal exocortex, it reads `src/AGENTS.md` via that symlink.

If you're here directly — e.g. maintaining org-level context (team pages, mission, conventions) without a personal exocortex loaded — start by reading [`src/AGENTS.md`](src/AGENTS.md).

For contribution conventions, see [`CONTRIBUTING.md`](CONTRIBUTING.md).
